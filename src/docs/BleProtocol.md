# 蓝牙通信协议文档

## 概述

本文档描述了 SandWormApp 与硬件设备之间的蓝牙低功耗 (BLE) 通信协议。所有数据均通过单一特征值进行双向传输，使用 UTF-8 编码的字符串格式。

---

## 接收信号（设备 → App）

### 1. 位置数据 `POS`

上报设备当前 GPS 位置坐标。

| 字段 | 说明 |
|------|------|
| 前缀 | `POS:` |
| 格式 | `POS:<纬度>,<经度>` |
| 示例 | `POS:31.230416,121.473701` |

**字段说明：**
- `纬度` (lat): 浮点数，WGS84 坐标系
- `经度` (lng): 浮点数，WGS84 坐标系

---

### 2. 车辆电池电量 `BATTERY`

上报车辆/设备主电池电量。

| 字段 | 说明 |
|------|------|
| 前缀 | `BATTERY:` |
| 格式 | `BATTERY:<电量值>` |
| 示例 | `BATTERY:85` |

**字段说明：**
- `电量值`: 整数，范围 0-100，表示百分比

---

### 3. 遥控器电池电量 `REMOTE_BATTERY`

上报遥控器电池电量。

| 字段 | 说明 |
|------|------|
| 前缀 | `REMOTE_BATTERY:` |
| 格式 | `REMOTE_BATTERY:<电量值>` |
| 示例 | `REMOTE_BATTERY:92` |

**字段说明：**
- `电量值`: 整数，范围 0-100，表示百分比

---

### 4. 工作进度 `PROGRESS`

上报当前任务执行进度。

| 字段 | 说明 |
|------|------|
| 前缀 | `PROGRESS:` |
| 格式 | `PROGRESS:<进度值>` |
| 示例 | `PROGRESS:45` |

**字段说明：**
- `进度值`: 整数，范围 0-100，表示百分比

---

### 5. 金属检测结果 `DETECT`

上报金属探测器检测到的目标信息。

| 字段 | 说明 |
|------|------|
| 前缀 | `DETECT:` |
| 格式 | `DETECT:<纬度>,<经度>[,<金属类型>][,<深度>]` |
| 示例 | `DETECT:31.230416,121.473701,iron,0.5` |

**字段说明：**
- `纬度` (lat): 浮点数，必填
- `经度` (lng): 浮点数，必填
- `金属类型` (metalType): 字符串，可选（如 `iron`, `copper`, `gold` 等）
- `深度` (depth): 浮点数，可选，单位：米

**简化示例：**
```
DETECT:31.230416,121.473701              // 仅位置
DETECT:31.230416,121.473701,iron         // 位置 + 金属类型
DETECT:31.230416,121.473701,iron,0.5     // 完整信息
```

## 发送信号（App → 设备）

### 1. 控制指令

控制设备的运行状态。

| 指令 | 说明 | 格式 |
|------|------|------|
| `START` | 开始执行任务 | `START` |
| `PAUSE` | 暂停当前任务 | `PAUSE` |
| `STOP` | 停止并终止任务 | `STOP` |

**示例：**
```
START
PAUSE
STOP
```

---

### 2. 路径数据 `PATH`

发送规划好的路径坐标序列。

| 字段 | 说明 |
|------|------|
| 前缀 | `PATH:` |
| 格式 | `PATH:<JSON数组>` |

**JSON 结构：**
```json
[
  {"lat": 31.230416, "lng": 121.473701},
  {"lat": 31.230516, "lng": 121.473801},
  {"lat": 31.230616, "lng": 121.473901}
]
```

**完整示例：**
```
PATH:[{"lat":31.230416,"lng":121.473701},{"lat":31.230516,"lng":121.473801},{"lat":31.230616,"lng":121.473901}]
```

**字段说明：**
- 数组中每个对象包含 `lat`（纬度）和 `lng`（经度）
- 坐标使用 WGS84 坐标系
- 路径点按执行顺序排列

## 技术规格

### 蓝牙配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Service UUID | 配置文件中定义 | 蓝牙服务 UUID |
| Characteristic UUID | 配置文件中定义 | 读写特征值 UUID |
| 连接超时 | `BLE_CONFIG.CONNECT_TIMEOUT_MS` | 毫秒 |

### 数据编码

- **传输编码**: Base64
- **内容编码**: UTF-8 字符串
- **坐标系**: WGS84

### 错误码

| 错误码 | 说明 |
|--------|------|
| `PERMISSION_DENIED` | 蓝牙权限被拒绝 |
| `SCAN_FAILED` | 扫描设备失败 |
| `CONNECT_FAILED` | 连接设备失败 |
| `CONNECT_TIMEOUT` | 连接超时 |
| `SERVICE_NOT_FOUND` | 未找到蓝牙服务 |
| `CHARACTERISTIC_NOT_FOUND` | 未找到特征值 |
| `DEVICE_DISCONNECTED` | 设备已断开连接 |
| `WRITE_FAILED` | 数据发送失败 |
| `READ_FAILED` | 数据读取失败 |
| `NOT_CONNECTED` | 设备未连接 |

## 通信流程示例

```
App                          Device
 |                              |
 |-- [连接蓝牙] --------------->|
 |<------------ [连接成功] -----|
 |                              |
 |-- PATH:[...] --------------->|  发送路径
 |-- START -------------------->|  开始任务
 |                              |
 |<------------ POS:x,y --------|  位置更新
 |<------------ PROGRESS:10 ----|  进度更新
 |<------------ BATTERY:85 -----|  电量更新
 |<------------ DETECT:... -----|  检测结果
 |                              |
 |-- PAUSE -------------------->|  暂停
 |-- START -------------------->|  继续
 |                              |
 |<------------ PROGRESS:100 ---|  完成
 |-- STOP --------------------->|  停止
 |                              |
```
